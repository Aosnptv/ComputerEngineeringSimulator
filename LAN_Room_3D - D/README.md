# LAN Networking 3D/VR Starter

โปรเจกต์ต้นแบบห้องฝึก LAN Networking
พัฒนาด้วย Python และ Panda3D

## สิ่งที่มีในเวอร์ชันนี้

- ห้องฝึก 3D
- สถานีฝึก LAN จำนวน 9 จุด
- การเดินด้วย W, A, S, D
- การหมุนมุมมองด้วยลูกศรซ้ายและขวา
- ตัวจับเวลา 10 นาที
- ระบบหยุดและรีเซ็ตเวลา

## วิธีติดตั้ง

เปิด Terminal ในโฟลเดอร์โปรเจกต์

สร้าง virtual environment:

python -m venv .venv

ติดตั้ง Panda3D:

.\.venv\Scripts\python.exe -m pip install -r requirements.txt

## วิธีเปิดเกม

.\.venv\Scripts\python.exe main.py

## ปุ่มควบคุม

- W A S D: เดิน
- ลูกศรซ้าย/ขวา: หมุนมุมมอง
- Enter: เริ่มเวลา
- P: หยุดหรือเล่นต่อ
- R: รีเซ็ตเวลา
- Esc: ออกจากเกม

## สถานะการพัฒนา

เวอร์ชันนี้เป็นต้นแบบ 3D สำหรับคอมพิวเตอร์
ยังไม่มีระบบหยิบจับอุปกรณ์ ภารกิจให้คะแนน
หรือการเชื่อมต่อแว่น VR จริง

จะพัฒนาระบบเหล่านี้ในขั้นตอนถัดไป
