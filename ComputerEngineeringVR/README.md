# Computer Engineering VR

โปรเจกต์ตัวอย่างห้องเรียนวิศวกรรมคอมพิวเตอร์ที่สร้างด้วย Panda3D

## เริ่มใช้งาน (Windows)

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src\main.py
```

เมื่อเปิดโปรแกรมจะเห็น Intro โลโก้ CPE ประมาณ 3.5 วินาที สามารถกด **Skip** ได้ จากนั้นเลือก **ภาษาไทย** หรือ **English** เพื่อเข้าห้อง 3D

## การควบคุม

- `W A S D` เดิน
- กดเมาส์ขวาค้างแล้วลากเพื่อหันและเงยกล้อง (หรือใช้ `← →` เพื่อหัน)
- `E` คุยกับหุ่นยนต์หรือเปิดสถานีเมื่อเดินเข้าใกล้
- `Esc` ออกจากโปรแกรม

สถานีความรู้ 6 แห่งอยู่สองฝั่งของห้อง สามารถเปิดจากปุ่มด้านขวาได้เช่นกัน

คลิก **จอคอมกลางห้องหลัก** เพื่อเลือกห้อง 1 ประกอบคอมพิวเตอร์, ห้อง 2 LAN และเครือข่าย หรือห้อง 3 การเขียนโปรแกรม เดินเข้าใกล้คอมแล้วกด `E` ได้เช่นกัน แต่ละห้องมีคำถาม 3 ระดับ เมื่อผ่านแล้วไปห้องถัดไปได้ หรือกดกลับห้องหลัก
