# Computer Engineering VR

เกมรวมการเรียนรู้วิศวกรรมคอมพิวเตอร์ที่สร้างด้วย Panda3D โดยใช้ `ShowBase`
เดียวสำหรับ Main Hub, PC Assembly, LAN Networking และ Programming Room

## เริ่มใช้งาน (Windows)

ดับเบิลคลิก `..\run.bat` จาก repository root ตัว launcher จะตรวจ Python 3.12
x64 และ Panda3D 1.10.16 ก่อนเริ่มเกม โดยไม่ติดตั้งแพ็กเกจอัตโนมัติ

เมื่อเปิดโปรแกรมจะพบ Main Menu ซึ่งมี Start Game, Settings, Language และ Quit

## การควบคุม

- `W A S D` เดิน
- ใช้เมาส์หันมองตามคำแนะนำของแต่ละห้อง
- `E` คุยกับหุ่นยนต์หรือเปิดสถานีเมื่อเดินเข้าใกล้
- `Esc` เปิด Pause Menu

สถานีความรู้ 6 แห่งอยู่สองฝั่งของห้อง สามารถเปิดจากปุ่มด้านขวาได้เช่นกัน

คลิก **จอคอมกลางห้องหลัก** เพื่อเลือกห้อง 1 ประกอบคอมพิวเตอร์, ห้อง 2 LAN
และเครือข่าย หรือห้อง 3 การเขียนโปรแกรม ห้อง LAN และ Programming ใช้กลไก
ต้นฉบับ ไม่ใช่คำถาม placeholder
