Root cause ที่มีหลักฐาน: Panda3D render states บน Intel/WGL เก็บ native state ที่อ้างถึง light NodePath ชุดใหม่ เมื่อ Hub/PC สร้าง lights ใหม่ทุก lifecycle geometry จำนวนมากจึงทำให้ handle และ prepared graphics resources โตเชิงเส้น การ reuse light NodePaths เดิมหยุดทั้ง handle, texture และ buffer growth โดยคงสี/ทิศ/ตำแหน่ง/attenuation เดิม

หลักฐานหลัก:

- `resource-hub-10.json`, `resource-hub-lit-environment-3.json`, `resource-hub-after-shared-lights-10.json`
- `resource-pc-after-shared-lights-10.json` (ก่อน PC-light fix), `resource-pc-shared-lights-3.json`, `resource-pc-after-shared-lights-production-10.json`
