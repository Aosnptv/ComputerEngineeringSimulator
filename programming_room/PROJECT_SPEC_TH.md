# 1. ภาพรวมโครงการ

Programming Room เป็นเกมการศึกษาที่พัฒนาขึ้นเพื่อส่งเสริมการเรียนรู้พื้นฐานการเขียนโปรแกรมผ่านการเล่นเกม

ผู้เล่นสามารถเดินสำรวจห้องเรียน 3 มิติ ทำแบบฝึกหัด และควบคุมหุ่นยนต์ผ่านบล็อกคำสั่ง

แนวคิดของโครงการคือการเปลี่ยนเนื้อหาการเขียนโปรแกรมให้เป็นกิจกรรมที่ผู้เรียนสามารถทดลอง แก้ไข และเรียนรู้จากข้อผิดพลาดได้

เกมมุ่งเน้นการเรียนรู้ผ่านการลงมือปฏิบัติ มากกว่าการอ่านเนื้อหาเพียงอย่างเดียว

# 9. Programming Activities

ระบบกิจกรรมการเขียนโปรแกรมประกอบด้วย 3 แบบฝึกหัดหลัก

## 9.1 Arrange Blocks

ผู้เล่นต้องเรียงลำดับบล็อกคำสั่งให้ถูกต้อง

วัตถุประสงค์:

- ฝึกการคิดเป็นลำดับ
- เข้าใจการทำงานของคำสั่ง
- ฝึกการแก้ปัญหา

## 9.2 Find the Bug

ผู้เล่นต้องค้นหาคำสั่งที่ผิดจากโจทย์

วัตถุประสงค์:

- ฝึกวิเคราะห์โค้ด
- ฝึกตรวจสอบข้อผิดพลาด
- ฝึกการแก้ไขปัญหา

## 9.3 Fill Missing Block

ผู้เล่นต้องเติมคำสั่งที่หายไปให้ถูกต้อง

วัตถุประสงค์:

- ฝึกความเข้าใจลำดับคำสั่ง
- ฝึกเลือกคำสั่งให้เหมาะสม
- ฝึกการคิดเชิงตรรกะ

# 10. ข้อกำหนดของแบบฝึกหัด

แบบฝึกหัดแต่ละประเภทต้องมีจำนวน 3 ข้อ

## 10.1 กติกาการตอบ

- ผู้เล่นตอบได้ครั้งเดียวต่อข้อ
- ไม่สามารถแก้คำตอบหลังส่งได้
- หากตอบผิดจะได้รับ 0 คะแนน
- ระบบเปลี่ยนไปข้อถัดไปโดยอัตโนมัติ

## 10.2 การให้คะแนน

| ผลลัพธ์ | คะแนน |
|---|---|
| ตอบถูก | 100 |
| ตอบผิด | 0 |

คะแนนสูงสุดต่อกิจกรรมคือ 300 คะแนน

## 10.3 หน้าสรุปผล

เมื่อทำครบ 3 ข้อ ระบบต้องแสดง

- จำนวนข้อที่ตอบถูก
- คะแนนที่ได้รับ
- คะแนนรวม
- ตัวเลือกกลับไปยังเมนูกิจกรรม

# 11. ระบบ Robot Mission

Robot Mission เป็นกิจกรรมหลักที่ใช้ฝึกการสั่งงานหุ่นยนต์ด้วยบล็อกคำสั่ง

ผู้เล่นต้องกำหนดลำดับคำสั่งเพื่อให้หุ่นยนต์ทำภารกิจสำเร็จ

## 11.1 สนามจำลอง

สนามจำลองเป็นตารางขนาด 5 × 5 ช่อง

ประกอบด้วย

- ตำแหน่งเริ่มต้นของหุ่นยนต์
- ช่องทางเดิน
- สิ่งกีดขวาง
- แบตเตอรี่
- จุดหมายปลายทาง

## 11.2 ภารกิจ

มีทั้งหมด 5 ด่าน

1. First Steps
2. Turning Robot
3. Battery Hunt
4. Avoid Obstacles
5. Final Mission

## 11.3 เงื่อนไขผ่านภารกิจ

ผู้เล่นต้องสั่งให้หุ่นยนต์ทำงานตามเงื่อนไขของด่าน

เช่น

- เดินถึงจุดหมาย
- เลี้ยวตามเส้นทาง
- เก็บแบตเตอรี่
- หลบสิ่งกีดขวาง

เมื่อทำภารกิจสำเร็จ ระบบจะแสดงหน้าสรุปผล

# 12. ระบบบล็อกคำสั่ง

คำสั่งที่รองรับประกอบด้วย

| คำสั่ง | ความหมาย |
|---|---|
| FORWARD | เดินหน้า |
| TURN LEFT | เลี้ยวซ้าย |
| TURN RIGHT | เลี้ยวขวา |
| IF OBSTACLE | ตรวจสอบสิ่งกีดขวางด้านหน้า |
| ELSE | กำหนดคำสั่งเมื่อเงื่อนไขไม่เป็นจริง |
| END IF | สิ้นสุดเงื่อนไข |

ผู้เล่นสามารถเพิ่มและจัดลำดับบล็อกคำสั่งได้

เมื่อกด RUN ระบบจะอ่านคำสั่งตามลำดับและสั่งให้หุ่นยนต์ทำงาน

หากคำสั่งไม่ถูกต้อง ระบบจะแจ้งข้อผิดพลาด

# 13. ระบบ IF / ELSE

ระบบ IF / ELSE ช่วยให้หุ่นยนต์ตัดสินใจตามเงื่อนไข

ตัวอย่าง:

```text
IF OBSTACLE
    TURN LEFT
ELSE
    FORWARD
END IF
```

การทำงาน:

1. ตรวจสอบช่องด้านหน้าของหุ่นยนต์
2. หากพบสิ่งกีดขวาง ให้ทำคำสั่งในส่วน IF
3. หากไม่พบสิ่งกีดขวาง ให้ทำคำสั่งในส่วน ELSE
4. เมื่อจบเงื่อนไข ให้ทำคำสั่งถัดไป

ระบบใช้ตัวแปลคำสั่งบล็อกภายในเกม

ไม่ได้รันโค้ด Python หรือ C ของผู้เล่นโดยตรง

# 14. ระบบระดับความยาก

Robot Mission รองรับ 3 ระดับ

## Easy

- สิ่งกีดขวางน้อย
- คำสั่งไม่ซับซ้อน
- มีตัวอย่างการทำภารกิจ
- เหมาะสำหรับผู้เริ่มต้น

## Medium

- สิ่งกีดขวางเพิ่มขึ้น
- ต้องวางแผนเส้นทางมากขึ้น
- ใช้คำสั่งหลายขั้นตอน

## Hard

- สิ่งกีดขวางมากขึ้น
- ต้องใช้คำสั่งเงื่อนไข
- บังคับให้มี IF OBSTACLE, ELSE และ END IF
- เพิ่มความซับซ้อนของภารกิจ

# 18. ระบบระดับภาษา

กิจกรรมบางประเภทสามารถเลือกแสดงคำสั่งในรูปแบบ Python หรือ C-style

ตัวอย่าง:

| คำสั่ง | Python | C-style |
|---|---|---|
| เดินหน้า | robot.move_forward() | move_forward(); |
| เลี้ยวซ้าย | robot.turn_left() | turn_left(); |
| เลี้ยวขวา | robot.turn_right() | turn_right(); |

ระบบรองรับเฉพาะรูปแบบคำสั่งที่กำหนดไว้

ไม่ใช่ระบบรันโค้ดทั่วไปหรือคอมไพเลอร์ C เต็มรูปแบบ
