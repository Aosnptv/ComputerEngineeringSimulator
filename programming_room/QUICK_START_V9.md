# Programming Room — Quick Start Guide

คู่มือเริ่มต้นใช้งานเกม Programming Room

**อัปเดตล่าสุด:** 25 ตุลาคม 2026

## 1. เกี่ยวกับโปรเจกต์

Programming Room เป็นเกมฝึกพื้นฐานการเขียนโปรแกรมในรูปแบบห้องเรียน 3 มิติ พัฒนาด้วย Python และ Panda3D

ภายในเกมมีระบบหลักดังนี้

- Main Hub — ห้องโถงหลักสำหรับเลือกห้องเรียน
- Programming Room — ห้องเรียนเขียนโปรแกรม
- Programming Activities — แบบฝึกหัดพื้นฐานการเขียนโปรแกรม
- Robot Mission — ภารกิจควบคุมหุ่นยนต์ผ่านบล็อกคำสั่ง
- Score System — ระบบคะแนนและดาว

เกมเป็น Desktop Application สำหรับคอมพิวเตอร์ ไม่จำเป็นต้องใช้แว่น VR

---

## 2. สิ่งที่ต้องติดตั้ง

- Python 3.12
- Panda3D
- Windows
- Visual Studio Code (แนะนำ แต่ไม่จำเป็น)

---

## 3. วิธีเปิดโปรเจกต์

1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ `programming_lab_final`
3. เปิด Terminal หรือ PowerShell ในโฟลเดอร์ที่มี `main.py`
4. ติดตั้งไลบรารี

```powershell
python -m pip install -r requirements.txt
```

5. เปิดเกม

```powershell
python main.py
```

หากติดตั้ง Panda3D ไว้แล้ว ไม่จำเป็นต้องติดตั้งใหม่ทุกครั้ง

**สำคัญ:** ต้องรันคำสั่งในโฟลเดอร์เดียวกับ `main.py` และ `requirements.txt`

## 5. วิธีเข้า Programming Room

## 6. วิธีเปิดกิจกรรม

เมื่ออยู่ใน Programming Room

1. ใช้ W A S D เดินสำรวจห้อง
2. เดินเข้าใกล้คอมพิวเตอร์
3. เมื่อข้อความแจ้งให้ใช้งานปรากฏ ให้กด E
4. เลือกกิจกรรมที่ต้องการ

กิจกรรมประกอบด้วย

1. Arrange Blocks
2. Find the Bug
3. Fill Missing Block
4. Robot Mission

---

## 7. แบบฝึกหัดการเขียนโปรแกรม

### Arrange Blocks

เรียงบล็อกคำสั่งให้ถูกต้องตามโจทย์

### Find the Bug

วิเคราะห์และค้นหาคำสั่งที่ผิด

### Fill Missing Block

เลือกหรือเติมคำสั่งที่ขาดหายไป

### กติกาการตอบคำถาม

- แต่ละกิจกรรมมี 3 ข้อ
- ตอบได้เพียง 1 ครั้งต่อข้อ
- ตอบถูกได้รับ 100 คะแนน
- ตอบผิดได้รับ 0 คะแนน
- เมื่อตอบผิด ระบบจะไปข้อถัดไปอัตโนมัติ
- เมื่อครบ 3 ข้อ ระบบจะแสดงหน้าสรุปคะแนน

คะแนนสูงสุดต่อกิจกรรมคือ 300 คะแนน

## 8. Robot Mission

Robot Mission เป็นเกมควบคุมหุ่นยนต์บนกระดานจำลอง

ผู้เล่นต้องใช้คำสั่งเพื่อควบคุมหุ่นยนต์ให้ทำภารกิจสำเร็จ

### ด่านทั้งหมด

1. First Steps
2. Turning Robot
3. Battery Hunt
4. Avoid Obstacles
5. Final Mission

### คำสั่งที่ใช้

- FORWARD
- TURN LEFT
- TURN RIGHT
- IF OBSTACLE
- ELSE
- END IF

### วิธีเล่น

1. เลือก Robot Mission
2. เลือกด่าน
3. เลือกระดับความยาก
4. เพิ่มบล็อกคำสั่งจากแผง PROGRAMMING ด้านขวา
5. ตรวจสอบลำดับคำสั่งใน YOUR PROGRAM
6. กด RUN
7. สังเกตการเคลื่อนที่ของหุ่นยนต์
8. เมื่อผ่านด่าน ระบบจะแสดงคะแนนและดาว

หากคำสั่งผิดพลาดสามารถแก้ไขแล้วทดลองใหม่ได้

---

## 9. ระดับความยาก

### Easy

- สิ่งกีดขวางน้อย
- เหมาะสำหรับผู้เริ่มต้น
- มีปุ่ม LOAD DEMO สำหรับโหลดคำสั่งตัวอย่าง

### Medium

- สิ่งกีดขวางเพิ่มขึ้น
- ต้องวางแผนเส้นทางมากขึ้น
- ใช้คำสั่งหลายขั้นตอน

### Hard

- สิ่งกีดขวางมากขึ้น
- ต้องใช้เงื่อนไขในการตัดสินใจ
- ต้องมี IF OBSTACLE, ELSE และ END IF

---

## 10. ตัวอย่าง IF / ELSE

```text
IF OBSTACLE
    TURN LEFT
ELSE
    FORWARD
END IF
```

คำอธิบาย

- ถ้าด้านหน้ามีสิ่งกีดขวาง ให้หุ่นยนต์เลี้ยวซ้าย
- ถ้าด้านหน้าไม่มีสิ่งกีดขวาง ให้หุ่นยนต์เดินหน้า
- END IF ใช้ปิดชุดคำสั่งเงื่อนไข

ระบบจะตรวจสอบสิ่งกีดขวางจากสถานะของหุ่นยนต์ในเกม

---

## 11. ระบบดาว

Robot Mission ใช้ดาวแสดงผลความสำเร็จ

- ก่อนเล่น ดาวเป็นสีเทา
- ผ่านด่านแล้ว ดาวที่ได้รับเปลี่ยนเป็นสีทอง
- สามารถได้รับดาว 1–3 ดวงเมื่อผ่านด่าน
- จำนวนดาวขึ้นอยู่กับเวลา จำนวนข้อผิดพลาด และระดับความยาก

เมื่อเริ่มเกมรอบใหม่ ดาวจะเริ่มเป็นสีเทา

## 13. ระบบ HOW TO PLAY

เมื่อเข้าสู่ Robot Mission ครั้งแรก จะมีหน้าต่าง HOW TO PLAY แนะนำการใช้งาน

กด GOT IT เพื่อปิดหน้าต่างและเริ่มเล่น

หากต้องการเปิดคำแนะนำอีกครั้ง ให้กดปุ่ม ? HOW TO PLAY

หากกด RUN โดยยังไม่มีบล็อกคำสั่ง ระบบจะแสดงข้อความแนะนำให้เพิ่มบล็อกก่อน

---

## 14. วิธีออกจาก Programming Room

สามารถกลับ Main Hub ได้ 2 วิธี

### วิธีที่ 1: ประตู EXIT

1. เดินไปยังประตู EXIT สีเขียว
2. รอจนขึ้นข้อความ EXIT DOOR READY
3. กด E
4. เกมจะกลับ Main Hub

### วิธีที่ 2: ปุ่ม BACK TO MAIN HUB

กดปุ่ม BACK TO MAIN HUB ที่ด้านขวาบนของหน้าจอ

ระบบจะกลับไปยัง Main Hub ทันที

### การแก้ไขล่าสุด

ระบบปรับพื้นที่ตรวจจับประตู EXIT และป้องกันการรับปุ่ม E ซ้ำระหว่างเปลี่ยนฉาก เพื่อไม่ให้เกมกลับเข้า Programming Room ทันทีหลังออกจากห้อง

## 15. ทดสอบโค้ด

เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วใช้คำสั่ง

```powershell
python -m unittest discover -s tests -v
```

ผลการตรวจสอบล่าสุด:

- ผ่าน 37 การทดสอบ
- ตรวจไวยากรณ์ Python ผ่าน 26 ไฟล์
- ไฟล์ ZIP ตรวจสอบความสมบูรณ์ผ่าน

การทดสอบเหล่านี้เป็นการตรวจตรรกะและโครงสร้างโค้ด ยังควรเปิดเกมจริงบน Windows เพื่อตรวจการแสดงผลและตำแหน่งปุ่ม

## 16. แก้ปัญหาเบื้องต้น

### ไม่พบ requirements.txt

เปิด Terminal ให้ตรงกับโฟลเดอร์ที่มี `requirements.txt`

### ไม่พบ main.py

เข้าโฟลเดอร์ `programming_lab_final` ก่อนรันเกม

### เปิดเกมไม่ได้

ตรวจสอบ Panda3D ด้วยคำสั่ง

```powershell
python -c "import panda3d"
```

### กด RUN แล้วหุ่นยนต์ไม่เดิน

ตรวจสอบว่ามีคำสั่งใน YOUR PROGRAM ก่อนกด RUN

### กด E ที่ EXIT แล้วไม่กลับ Main Hub

- ตรวจสอบว่าขึ้น EXIT DOOR READY
- ตรวจสอบว่าใช้ `main_hub.py` รุ่นแก้การรับ E ซ้ำแล้ว
- สามารถใช้ BACK TO MAIN HUB เป็นทางออกสำรองได้
