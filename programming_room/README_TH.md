# Programming Room

## เกมฝึกทักษะการเขียนโปรแกรมในห้องเรียน 3 มิติ

Programming Room เป็นเกมเพื่อการเรียนรู้พื้นฐานการเขียนโปรแกรม พัฒนาด้วยภาษา Python และ Panda3D

ผู้เล่นสามารถเดินสำรวจห้องเรียน 3 มิติ ทำแบบฝึกหัดการเขียนโปรแกรม และควบคุมหุ่นยนต์ผ่านคำสั่งต่าง ๆ เพื่อทำภารกิจให้สำเร็จ

โปรเจกต์นี้ออกแบบมาเพื่อช่วยให้ผู้เรียนเข้าใจหลักการเขียนโปรแกรมผ่านการลงมือปฏิบัติจริงในรูปแบบเกม

**อัปเดตล่าสุด:** 25 ตุลาคม 2026

---

- Object-Oriented Programming (OOP)

## 4. การติดตั้งและเปิดเกม

### 4.1 ติดตั้ง Python

ติดตั้ง Python 3.12 ลงบนคอมพิวเตอร์

ตรวจสอบเวอร์ชันด้วยคำสั่ง

```powershell
python --version
```

### 4.2 เปิดโปรเจกต์

1. แตกไฟล์ ZIP
2. เปิด Visual Studio Code
3. เลือก File > Open Folder
4. เลือกโฟลเดอร์ `programming_lab_final`
5. ตรวจสอบว่ามีไฟล์ `main.py` และ `requirements.txt`

### 4.3 ติดตั้ง Panda3D

เปิด Terminal ใน VS Code

พิมพ์คำสั่ง

```powershell
python -m pip install -r requirements.txt
```

รอจนกว่าการติดตั้งจะเสร็จสมบูรณ์

### 4.4 เปิดเกม

พิมพ์คำสั่ง

```powershell
python main.py
```

เมื่อโปรแกรมทำงาน หน้าต่างเกม Programming Room จะเปิดขึ้นมา

**หมายเหตุ:** หากขึ้นข้อความว่าไม่พบ `main.py` หรือ `requirements.txt` ให้ตรวจสอบว่ากำลังเปิด Terminal ในโฟลเดอร์ที่ถูกต้อง

### วิธีออกจาก Programming Room

## 8. กิจกรรมฝึกเขียนโปรแกรม

### 8.1 Arrange Blocks

กิจกรรมเรียงลำดับบล็อกคำสั่ง

ผู้เล่นต้องนำบล็อกคำสั่งมาเรียงลำดับให้ถูกต้องตามโจทย์

วัตถุประสงค์:

- ฝึกคิดอย่างเป็นลำดับขั้นตอน
- ฝึกแก้ปัญหา
- เรียนรู้การทำงานของคำสั่ง

### 8.2 Find the Bug

กิจกรรมค้นหาข้อผิดพลาดในโปรแกรม

ผู้เล่นต้องวิเคราะห์โจทย์และเลือกคำสั่งที่ไม่ถูกต้อง

วัตถุประสงค์:

- ฝึกวิเคราะห์โค้ด
- ฝึกตรวจหาข้อผิดพลาด
- พัฒนาทักษะการแก้ปัญหา

### 8.3 Fill Missing Block

กิจกรรมเติมคำสั่งที่หายไป

ผู้เล่นต้องเลือกคำสั่งที่เหมาะสมเพื่อทำให้โปรแกรมสมบูรณ์

วัตถุประสงค์:

- ฝึกทำความเข้าใจลำดับคำสั่ง
- ฝึกการใช้คำสั่งควบคุม
- ฝึกการคิดเชิงตรรกะ

## 9. ระบบคะแนนแบบฝึกหัด

กิจกรรมแบบฝึกหัดแต่ละประเภทมีทั้งหมด 3 ข้อ

ระบบกำหนดให้ผู้เล่นตอบได้เพียง 1 ครั้งต่อข้อ

### เงื่อนไขการให้คะแนน

| ผลการตอบ | คะแนน |
|---|---|
| ตอบถูก | 100 คะแนน |
| ตอบผิด | 0 คะแนน |

### การทำงานของระบบ

1. ผู้เล่นเลือกคำตอบ
2. ระบบตรวจสอบความถูกต้อง
3. บันทึกคะแนนตามคำตอบ
4. เปลี่ยนไปยังข้อถัดไปโดยอัตโนมัติ
5. เมื่อครบ 3 ข้อ จะแสดงหน้าสรุปคะแนน

หากตอบผิด จะไม่สามารถย้อนกลับไปตอบข้อเดิมซ้ำได้ในรอบกิจกรรมนั้น

คะแนนรวมของแบบฝึกหัดแต่ละกิจกรรมสูงสุด 300 คะแนน

## 10. ระบบ Robot Mission

2. Turning Robot

- TURN LEFT
- TURN RIGHT
- IF OBSTACLE
- ELSE
- END IF

## 11. ระบบระดับความยาก

### Hard

ระดับยาก

- ต้องมีคำสั่ง IF OBSTACLE, ELSE และ END IF
- เหมาะสำหรับฝึกการคิดเชิงตรรกะ

## 12. ระบบ IF / ELSE

ระบบ IF / ELSE ใช้สำหรับให้หุ่นยนต์ตัดสินใจตามสถานการณ์

ตัวอย่าง:

```text
IF OBSTACLE
    TURN LEFT
ELSE
    FORWARD
END IF
```

ความหมาย:

- IF OBSTACLE: ตรวจสอบว่าด้านหน้ามีสิ่งกีดขวางหรือไม่
- TURN LEFT: หากมีสิ่งกีดขวาง ให้เลี้ยวซ้าย
- ELSE: หากไม่พบสิ่งกีดขวาง
- FORWARD: ให้เดินหน้า
- END IF: สิ้นสุดเงื่อนไข

ระบบจะตรวจสอบสิ่งกีดขวางด้านหน้าของหุ่นยนต์ระหว่างทำงาน

Programming Score = 700

## 15. โหมด Python และ C-style

กิจกรรมบางประเภทมีตัวเลือกแสดงคำสั่งในรูปแบบ Python หรือ C-style

### ตัวอย่างคำสั่ง

| การทำงาน | Python | C-style |
|---|---|---|
| เดินหน้า | robot.move_forward() | move_forward(); |
| เลี้ยวซ้าย | robot.turn_left() | turn_left(); |
| เลี้ยวขวา | robot.turn_right() | turn_right(); |

ระบบตรวจสอบเฉพาะคำสั่งที่อนุญาต

ไม่ได้ประมวลผล Python หรือ C ที่ผู้เล่นกรอกโดยตรง

## 18. การแก้ปัญหาเบื้องต้น

### ไม่พบไฟล์ requirements.txt

ตรวจสอบว่าเปิด Terminal ในโฟลเดอร์ `programming_lab_final`

### ไม่พบไฟล์ main.py

ตรวจสอบตำแหน่งโฟลเดอร์ก่อนรันคำสั่ง

### ไม่สามารถเปิดเกมได้

ตรวจสอบว่าติดตั้ง Python และ Panda3D แล้ว

สามารถใช้คำสั่ง

```powershell
python -c "import panda3d"
```

หากไม่มีข้อผิดพลาด แสดงว่า Python สามารถนำเข้า Panda3D ได้

### กด RUN แล้วหุ่นยนต์ไม่เดิน

ตรวจสอบว่าเพิ่มบล็อกคำสั่งลงใน YOUR PROGRAM แล้ว

### กด E ที่ประตู EXIT แล้วไม่ออกจากห้อง

1. ตรวจสอบว่าขึ้นข้อความ EXIT DOOR READY
2. กด E หนึ่งครั้ง
3. หากยังมีปัญหา สามารถใช้ปุ่ม BACK TO MAIN HUB ได้
4. ตรวจสอบว่าใช้งานไฟล์ `main_hub.py` รุ่นที่แก้ปัญหาการกด E ซ้ำแล้ว
