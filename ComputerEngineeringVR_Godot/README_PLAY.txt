COMPUTER ENGINEERING VR SIMULATOR

Desktop: run ComputerEngineeringVR.exe, choose Desktop Mode, then use WASD,
mouse look, and E or left-click to interact. Escape releases/captures the mouse.

VR: start SteamVR, confirm it is the active OpenXR runtime, connect an HTC Vive
or Valve Index, then launch the game and choose VR. If OpenXR initialization is
unavailable, return to Desktop Mode.

This educational simulation does not configure the host computer's network and
does not require Python, Blender, or Godot at runtime.
