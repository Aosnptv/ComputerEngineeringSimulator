# Asset credits and provenance

All new room geometry, furniture, equipment forms, materials, and UI are generated from original Godot primitives and project code. No third-party 3D model, texture, icon, music, or sound is included. Legacy screenshots and fonts were reviewed only as references and were not copied because the repository has no top-level license and the exact asset provenance is uncertain.

Godot Engine and OpenXR runtime components are external dependencies governed by their respective licenses. Distribution should include the Godot license generated by the official export templates.
