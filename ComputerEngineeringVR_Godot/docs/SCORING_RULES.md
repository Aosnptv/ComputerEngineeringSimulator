# Scoring rules

Correctness is `70 × passed objective weight / total objective weight`. Error control is `max(0, 20 − 2 × counted errors)`. For completed missions, time efficiency is `10 × min(1, target / active seconds)`; incomplete missions receive zero time points. The clamped total is rounded once to the nearest integer.

Stars: 90–100 = 3; 75–89 = 2; 60–74 = 1; below 60 = 0. Incomplete missions always receive zero. Targets match the master specification: PC 300/480/720 seconds; LAN and Programming 240/420/600 seconds.
